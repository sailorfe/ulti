* ulti 🦖👹

[[file:grim.png][ulti emacs]]

an emacs-native syntax highlight theme with automated ports, written in pure emacs lisp.

see also:

+ [[https://codeberg.org/sailorfe/perona.nvim][perona.nvim]]
+ [[https://codeberg.org/sailorfe/moonqueen.nvim][moonqueen.nvim]]
+ [[https://codeberg.org/sailorfe/luna.nvim][luna.nvim]]

** ports

+ [[https://codeberg.org/dnkl/foot][foot]]
+ [[https://github.com/emersion/mako][mako]]
+ shell
+ [[https://termux.dev][termux]]
+ tty

ports are automatically generated by ~ulti/export-targets~. to contribute, make a pull request with a new template under ~templates/~. refer to ~palette.json~ at project root for a complete table of hex colors and their names. so far, templates are modeled after [[https://github.com/folke/tokyonight.nvim][tokyonight.nvim]].
