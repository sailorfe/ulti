* ulti 🦖👹

[[file:grim.png]]

#+begin_quote
*mirrored to github from [[https://codeberg.org/sailorfe][codeberg]].* issues and PRs opened on github will be ignored.

an emacs theme with automated ports written in pure emacs lisp, inspired by the tobiroppo from /one piece/. currently supports [[https://orgmode.org][org-mode]], [[https://github.com/jrblevin/markdown-mode][markdown-mode]], [[https://magit.vc/][magit]], [[https://github.com/minad/corfu][corfu]], and [[https://github.com/akermu/emacs-libvterm][vterm]]. 

see also:

+ [[https://codeberg.org/sailorfe/perona.nvim][perona.nvim]]
+ [[https://codeberg.org/sailorfe/moonqueen.nvim][moonqueen.nvim]]
+ [[https://codeberg.org/sailorfe/luna.nvim][luna.nvim]]

** installation

*** =straight.el=

#+BEGIN_SRC lisp
  (straight-use-package
   '(ulti
     :type git
     :host codeberg
     :repo "sailorfe/ulti"))

  (add-to-list 'custom-theme-load-path (straight--build-dir "ulti"))
#+END_SRC

or

#+begin_src lisp
  (use-package ulti
      :straight(:host codeberg :repo "sailorfe/ulti")
      :config
      (add-to-list 'custom-theme-load-path (straight--build-dir "ulti")))
#+end_src

*** =package.el=

#+begin_src lisp
  (use-package ulti
      :vc (:url "https://codeberg.org/sailorfe/ulti")
      :ensure t
      :config (load-theme 'ulti t))
#+end_src

external ports are automatically generated from templates using ={{variable}}= placeholders for keys that can be found in [[file:palette.json][palette.json]]. to contribute:

1. add a file to =templates/=.
2. edit =ulti/export-targets= at the bottom of [[file:ulti-theme.el][ulti-theme.el]] to include a list like =("templates/INPUT-FILE" . "extras/$APP/OUTPUT-FILE")=.
3. run [[file:scripts/build][./scripts/build]] and [[file:scripts/test][./scripts/test]]. test your build directly in the target application and repeat as needed.
4. make [[https://codeberg.org/sailorfe/ulti/pulls][a pull request]] committing your *template file*, *ulti-theme.el* and *your new extra* with a commit message like =feat(extra): add $APP=.
